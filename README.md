# clock_TFT_LCD_esp32

# Description
 Есть вот такой setup:
  - esp32-s3-N16R8
  - 3.5" TFT SPI
  - микроконтролер: 
    - нижний ряд слева на право: 3V3, 3V3, RST, 4, 5, 6, 15, 16, 17, 18, 8, 3, 46, 9, 10, 11, 12, 13, 14, 5V, GND
    - верхний ряд слева на право:  GND, TX, RX, 1, 2, 42, 41, 40, 39, 38, 37, 36, 35, 0, 45, 48, 47, 21, 20, 19,  GND, GND
 - esp32-s3 связан с диспелем следующим пинами: 
    - нижний ряд первый пин 3V3 + VCC
    - верхний ряд первый пин GND + GND экрана
    - нижний ряд пин 10 + CS
    - нижний ряд пин 8 + RESET
    - нижний ряд пин 9 + DC\RSy
    - нижний ряд пин 12 + SCK+T_CLK
    - нижний ряд пин 11 + SDI(MOSI)+T_DIN
    - нижний ряд пин 3 + LED
    - нижний ряд пин 13 + SDO(MISO)+T_DO
    - нижний ряд пин 4 + T_CS
    - верхний ряд пин 2 + T_IRQ
    - вывод SD-карты (SD_CS, SD_MOSI, SD_MISO, SD_SCK) пока не подключал.
